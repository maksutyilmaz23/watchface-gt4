# Huawei Watch GT4 Kadran Projesi

Huawei Watch GT4 (466x466 px) için saat kadranı geliştirme deposu.

## Dizin Yapısı
- `assets/raw/`: Ham tasarım dosyaları (PSD, PNG, SVG)
- `assets/processed/`: Theme Studio için optimize edilmiş PNG varlıkları
- `config/`: Kadran koordinat ve bileşen yapılandırmaları
- `scripts/`: Termux otomasyon betikleri
